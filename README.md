# Aurelia Zuri: prompts, tech stack and pseudocode

Design and build notes for the Aurelia Zuri website (Aurelia Developments; rooted in Africa, rising in Dubai).

The site's source code is in [jknlk/aurelia_zuri](https://github.com/jknlk/aurelia_zuri).

| File | What's in it |
| --- | --- |
| [PROMPT.md](PROMPT.md) | The full brief for the website, plus the follow-up requests that shaped it |
| [TECH_STACK.md](TECH_STACK.md) | Libraries and versions, project layout, scripts, performance notes |
| [PSEUDOCODE.md](PSEUDOCODE.md) | How each part works: loader, frame preloader, scroll film, floor tour, chapters |

**At a glance:** Vite + React 18, GSAP 3 with ScrollTrigger, Lenis smooth scroll, a canvas-drawn 300-frame film, inline SVG, plain CSS. A static site with no backend.

**Palette:** Chocolate `#4E342E` · Cream `#FFF8E7` · Burnt Orange `#CC5500`
